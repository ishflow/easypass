## Core API sözleşmesi (A yazar, B ve Host kullanır — İMZALAR DEĞİŞMEZ)

```csharp
namespace EasyPass.Core;

public sealed class Entry {           // WPF binding için set'li özellikler
  public string Id { get; set; } = Guid.NewGuid().ToString("N");
  public string FirstName { get; set; } = "";
  public string LastName { get; set; } = "";
  public string Extra1 { get; set; } = "";
  public string Extra2 { get; set; } = "";
  public string Username { get; set; } = "";
  public string Password { get; set; } = "";
  public DateTime UpdatedAt { get; set; } = DateTime.UtcNow;
  public string FullName => $"{FirstName} {LastName}".Trim();
}

public sealed class Vault {
  public string Path { get; }
  public IReadOnlyList<Entry> Entries { get; }            // salt okunur görünüm
  public static Vault Create(string path, string password); // yeni salt, boş kasa, diske yazar; dosya varsa IOException
  public static Vault Open(string path, string password);   // yanlış şifre → CryptographicException
  public static Vault Open(string path, byte[] key);        // önbellekteki anahtarla
  public static byte[] ReadSalt(string path);
  public byte[] Salt { get; }
  public byte[] Key { get; }                                 // önbelleğe yazmak için
  public bool ReloadIfChanged();                             // değiştiyse true
  public void Update(Action<List<Entry>> change);            // mutex + reload + change + atomik kaydet (+ .bak)
  public void ChangePassword(string newPassword);            // yeni salt, yeniden şifrele, kaydet
  public IReadOnlyList<Entry> Search(string query, int limit = 20);
}

public static class TextFold { public static string Fold(string s); } // Türkçe katlama, küçük harf

public static class AppPaths {                 // %APPDATA%\EasyPass (Environment.SpecialFolder.ApplicationData)
  public static string Dir { get; }
  public static string? VaultPath { get; set; } // settings.json {"vaultPath": "..."}; set → diske yazar
}

public static class KeyCache {                 // DPAPI CurrentUser, yalnız Windows; diğer OS: Save no-op, Load null
  public static void Save(byte[] salt, byte[] key);
  public static byte[]? Load(byte[] salt);      // salt eşleşmezse null
  public static void Clear();
}

public static class HostApi {                  // protokol mantığı, test edilebilir; Host Program yalnız çerçeveler
  public static JsonObject Handle(JsonObject request, Func<Vault?> getVault); // spec §5
}
```
`HostApi.Handle`: `getVault()` null dönerse `{ok:false,error:"locked"}`. Host'ta `getVault`:
`AppPaths.VaultPath` → `Vault.ReadSalt` → `KeyCache.Load` → `Vault.Open(path,key)`; açık kasada her istekte
`ReloadIfChanged()`.

## Görevler (paralel)

### Ajan A — Core + Host + testler
1. Testleri önce yaz (TDD): şifrele/çöz gidiş-dönüş; yanlış şifre CryptographicException; dosya bozuk
   (tag değişti) hata; `Update` sonrası yeniden açınca kayıt var ve `.bak` oluştu; `ReloadIfChanged`
   başka örneğin yazdığını görür; `ChangePassword` sonrası eski şifre açmaz yeni açar; `Search`
   ("ahmet", "AHMET", "sukru"→"Şükrü", iki kelime "ahmet yil", boş sorgu, limit); `HostApi` her komut +
   `check` dört sonucu + locked; Host çerçeveleme (uzunluk önekli okuma/yazma) bir test.
2. Kodu yaz, `~/.dotnet/dotnet test` yeşil.
3. Host `Program.cs`: stdin'den çerçeve oku → `HostApi.Handle` → stdout'a yaz → flush; stdin kapanınca
   çık; hiçbir şeyi stdout'a log'lama (stderr serbest). Mac'te elle dene: bir çerçeve gönder, yanıt al.
4. Performans: 5.000 kayıtla `Search` < 5 ms (testte Stopwatch ile assert, gevşek eşik 50 ms).

### Ajan B — WPF uygulaması (`src/EasyPass.App`)
- Core'a ProjectReference. `App.xaml` yok: `Program.Main` [STAThread] → `new Application` + `Theme.xaml`
  kaynakları → `MainWindow`. Ekranlar spec §7 ve tasarım kanvasıyla aynı (renkler spec'te).
- Akış: `AppPaths.VaultPath` yok/dosya yok → Kurulum; var → `KeyCache.Load(ReadSalt)` → açılırsa Ana
  ekran, değilse Kilit. Kilit açılınca `KeyCache.Save`. Kilitle → `KeyCache.Clear` + Kilit ekranı.
- Ana ekran: arama `Vault.Search` (boşsa tüm kayıtlar Ad-Soyad sıralı), liste, sağ panel düzenle; Kaydet →
  `Vault.Update`; Sil → onay sorusu → `Update`. Pencere `Activated` → `ReloadIfChanged` → listeyi yenile.
  Şifre kopyala → `Clipboard.SetText`. Yeni müşteri → boş panel.
- Ayarlar penceresi: kasa yolu + "Başka kasa aç", "Ana şifreyi değiştir" (eski+yeni×2), "Kilitle",
  Chrome bağlantısı: `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.easypass.host` var mı (Var/Yok).
- Tek ekran kodu basit tut: UserControl yerine MainWindow içinde Grid'ler + Visibility yeterli.
- Doğrulama: `~/.dotnet/dotnet build src/EasyPass.App -p:EnableWindowsTargeting=true` hatasız.
